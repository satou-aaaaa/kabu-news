# 株ニュース5本勝負

会社のニュースを読んで、株が**上がる**か**下がる**かを決める1日5本のゲームです。100万円（架空）をどこまで増やせるかを競います。

- 遊ぶ：https://satou-aaaaa.github.io/kabu-news/
- 「今日の5本」はだれでも同じ問題で1日1回。結果は絵文字の文でコピーして見せ合えます。練習は何度でも。
- 結果ごとに「なぜ動いたか」と株の言葉（織り込み済み・自社株買い・TOB など）を一言で覚えられます。
- 会社とニュースはすべて架空です。本当のお金は使わず、投資の助言でもありません。記録はあなたのブラウザの中だけに残ります。
- ホーム画面に置くと、電波が無くても遊べます。
